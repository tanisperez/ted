## Highlights

- **A new find bar**: the counter sits inside the field next to the options, and the field turns red when nothing matches. Find in selection is the fourth option, `Alt+L`. A wrong regular expression says what is wrong under the field. `Ctrl+Alt+Enter` replaces all, `Alt+P` toggles Preserve case, `F3` repeats the last search with the bar closed, and `Alt+Up` and `Alt+Down` go through the searches of the session.
- **File icons in the explorer**: code, text, data and configuration, scripts, images and archives each have their own icon and color.
- **Select opened file and Reload** in the explorer's header: the first shows the file of the active tab in the tree, the second reads the folders from disk again.
- **A lighter selection in the explorer**: the selected file is a soft gray with its name in the normal text color, and a thin ring shows while the explorer has the keyboard focus.
- **`Ctrl` and the mouse wheel change the font size** of the editor, as `Ctrl+=` and `Ctrl+-`; `Ctrl+0` brings it back.
- **The left panel keeps its width**: the width of the explorer and the Git panel is saved with the window and comes back on the next start.
- **Click the cursor position to go to a line**: `Ln 12, Col 5` in the status bar opens Go to line, as `Ctrl+G`.
- **Clearer fields and dialogs**: text fields have a stronger border and a focus ring, and the close button of dialogs is lighter and shows `Esc` in its tooltip.

## Fixes

- **`Ctrl+Space` no longer types a space** in the editor.
- **The explorer follows the files on disk**: a folder collapsed and expanded again shows the files created, renamed or deleted meanwhile, and a folder deleted and created again (a build output, a branch switch) keeps updating.
- **Scrollbars no longer cover the edge of the lists**: the counts and status letters of the Git panel, the change dots of the explorer, the end of the history rows and the Stage and Revert buttons of the diff stay clear of the scrollbar.
