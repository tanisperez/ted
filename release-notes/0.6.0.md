Markdown preview, more languages, syntax themes and a tidier Git panel.

## Highlights

- **Markdown preview**: an editor, a side by side and a preview view (`Ctrl+Shift+V`), a preview in its own tab, and links that show their target on hover. A bare URL is a link too.
- **Fold blocks of text** from the gutter (`Ctrl+Shift+[` and `Ctrl+Shift+]`), in code, Markdown sections and fenced code blocks.
- **Syntax themes**, with a Visual Studio Code one.
- **More languages**: TypeScript, TSX, SQL, properties, env files, Gradle, Java, Kotlin, YAML, Dockerfile and dotless shell config files.
- **New window** with `Ctrl+Shift+N`, and the window size is remembered between runs.
- **Recents can be removed**: the title bar switcher has an X next to each one.
- **New language menu** in the status bar (`Alt+L`), also an action of the global search, whose box now shows in file mode too.
- **Git in WSL**: a folder inside WSL uses the git of WSL.
- **What's new**: this tab, once after an update.

## Fixes

- The Git panel, the diff, the history and the explorer have visible scrollbars, and long diff lines scroll sideways.
- Wrapped text: the scrollbar reaches the end of the text, `Ctrl+End` keeps the cursor on screen, and a few very long lines scroll.
- The wheel scrolls the editor right after typing.
- `Esc` closes the find bar after a click.
- Markdown preview: a list item that starts with a link or bold text keeps it.
- The rows of the Git panel take its whole width, so the status letters line up.
