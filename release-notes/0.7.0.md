The editor now comes from telaio, shared with Postino.

## Highlights

- **Right-click menus** in every text field (the find bar, Go to line, the global search and the language menu) have ted's style on every platform and add Undo and Redo.
- **Fold all and Unfold all** in the editor's right-click menu: Fold all leaves only the first level of the file on screen. The menu ends with **Wrap lines**, checked while long lines wrap, as `Alt+Z`.
- **Menus open on click**: the file switcher, the branch menu and every other drop-down menu open when the mouse button is released, like a click on a button, instead of as soon as it is pressed.
- **Faster git diffs**: opening the diff of a changed file runs about three git commands instead of two plus one or two per change block, most noticeable inside WSL.
- **`ted` in a Windows terminal works like any other tool**: `ted --help` prints in cmd and PowerShell and the shell waits for it, its output can be piped, and opening a file from a terminal gives the prompt back at once.
- **XML declaration colored**: `<?xml version="1.0"?>`, DOCTYPE, processing instructions and CDATA are highlighted, with a grammar of their own for XML.
- **Updated libraries**: the UI toolkit moves to gpui-kit 0.10.0, and the other dependencies to their latest compatible versions.
