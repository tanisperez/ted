Settings

Open Settings with the gear at the top right or Ctrl ,. Every change applies at once and is saved to settings.toml; Reset values restores the defaults.

Insert spacesOnWhether Tab inserts spaces in a new or flat file. A file indented with tabs or spaces keeps its own style.

settings.toml

The settings live in a plain text file: ~/.config/ted/settings.toml on Linux, ~/Library/Application Support/ted/settings.toml on macOS and %APPDATA%\ted\settings.toml on Windows. You can edit it by hand while ted is closed; a value ted does not understand falls back to its default, and the rest of the file still applies. These keys exist only in the file, or are written only when set:

  • ui_font and mono_font, the font families, Geist and Geist Mono by default.
  • highlight_max_size_mb, 4 by default: files bigger than this many megabytes are not parsed for highlighting.
  • log_level, info by default: how much ted writes to its log file.
  • git_executable, absent by default: the path of the git executable, as picked in Settings.
```toml title="settings.toml" language = "auto" theme = "system" ui_font_size = 13.0 mono_font_size = 12.5 line_numbers = true highlight_current_line = true minimap = true word_wrap = false tab_size = 4 insert_spaces = true startup = "welcome" trim_trailing_whitespace = true insert_final_newline = true highlight_max_size_mb = 4 explorer_exclude = [".git", "target", "node_modules"] log_level = "info" git_fetch_automatically = true git_confirm_discard = true git_commit_action = "commit" ```
