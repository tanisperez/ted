Folders and tabs

Open a folder to work on several files: the explorer lists it, and each file you open gets a tab.

Opening a folder

Use Open folder… (Ctrl Shift O), a recent folder, or ted path/to/folder from a terminal. Opening another folder replaces the open one, after asking about any unsaved changes.

The explorer

See The interface for what it shows and its keys. The file in the editor is revealed and selected in the explorer. Alt 1, or the Files toggle of the status bar, shows or hides it.

Tabs

  • Opening a file that is already open shows its tab. A new tab goes right after the current one.
  • The + after the last tab, or Ctrl N, creates a new untitled document in a new tab; see New documents.
  • Each tab keeps its own scroll position, cursor and undo history, so switching is instant, even to a big log.
  • Ctrl Tab and Ctrl Shift Tab go to the next and previous tab, on every system.
  • The cross, a middle click or Ctrl W closes a tab. A tab with unsaved changes asks first.
  • Drag a tab to reorder it. When the tabs do not fit, the bar scrolls and its arrows and list button appear.

Several files without a folder

A file opened alone, with ted file.log or from the recents, stays in file mode: no explorer and no tabs. You can still open more next to it: Ctrl N adds a new document, for example to take notes while you read a log, and Open file… adds another file. ted a.txt b.txt opens both at once.

The tab bar shows while more than one file is open, and the title bar's switcher names the file shown. Closing the last one (Ctrl W) goes back to the welcome screen. Opening a folder replaces the files, after asking about any unsaved changes.
