Folders and tabs

Open a folder to work on several files: the explorer lists it, and each file you open gets a tab.

Opening a folder

Use Open folder… (Ctrl Shift O), a recent folder, or ted path/to/folder from a terminal. Opening another folder replaces the open one, after asking about any unsaved changes.

The explorer

See The interface for what it shows and its keys. The file in the editor is revealed and selected in the explorer. Alt 1, or the Files toggle of the status bar, shows or hides it. Right click a file or folder to copy its path, its path relative to the open folder, or to show it in your file manager; right click below the rows for the open folder itself.

Search files and actions

Ctrl K, or the search box of the title bar, opens a list at the top of the window. Type part of a file's name or path to find it in the open folder: the letters do not have to be together, so srb finds src/status_bar.rs, and a match in the file name comes before one in its folders. Type a / to match the folders too (state/root). With nothing typed it lists the recent files.

The same list holds the actions, with their keys: open a file or a folder, save, the panels, find, go to line, wrap, zoom, settings and the keyboard shortcuts. ↑ and ↓ move, Enter opens the file in a tab or runs the action, Esc closes the list.

The files searched are the ones the explorer would show: .gitignore and the Exclude setting apply. The folder is read again each time the list opens, in the background, so new files show up. In a folder with more than 200 000 files only the first ones are searched, and the list says so. Without a folder, Ctrl K lists the recent files and the actions.

Tabs

  • Opening a file that is already open shows its tab. A new tab goes right after the current one.
  • The + after the last tab, or Ctrl N, creates a new untitled document in a new tab; see New documents.
  • Each tab keeps its own scroll position, cursor and undo history, so switching is instant, even to a big log.
  • Ctrl Tab and Ctrl Shift Tab go to the next and previous tab, on every system.
  • The cross, a middle click or Ctrl W closes a tab. A tab with unsaved changes asks first.
  • Right click a tab for Close, Close others and, for a file, Copy path, Copy relative path and Show in file manager.
  • Drag a tab to reorder it. When the tabs do not fit, the bar scrolls and its arrows and list button appear.

Several files without a folder

A file opened alone, with ted file.log or from the recents, stays in file mode: no explorer and no tabs. You can still open more next to it: Ctrl N adds a new document, for example to take notes while you read a log, and Open file… adds another file. ted a.txt b.txt opens both at once.

The tab bar shows while more than one file is open, and the title bar's switcher names the file shown. Closing the last one (Ctrl W) goes back to the welcome screen. Opening a folder replaces the files, after asking about any unsaved changes.
