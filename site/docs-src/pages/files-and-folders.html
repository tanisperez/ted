title: Files and folders description: Where ted keeps its settings, its recent files list and its log file on each system. ---

Files and folders

ted keeps three files of its own. It never writes anywhere else except the files you save.

FileLinuxmacOSWindows
Settings~/.config/ted/settings.toml~/Library/Application Support/ted/settings.toml%APPDATA%\ted\settings.toml
Recent folders and files~/.config/ted/recents.toml~/Library/Application Support/ted/recents.toml%APPDATA%\ted\recents.toml
Log file~/.local/state/ted/ted.log~/Library/Logs/ted/ted.log%LOCALAPPDATA%\ted\logs\ted.log

On Linux, XDG_CONFIG_HOME and XDG_STATE_HOME move the first two and the last one.

Recent files

ted remembers the last ten folders and the last ten files you opened, most recent first. A recent entry that no longer exists leaves the list when you try to open it.

Network shares and WSL on Windows

On Windows, ted opens files and folders on network shares (\\server\share\notes.md, or a mapped drive such as Z:\) and inside WSL 2 distributions (\\wsl.localhost\Ubuntu\home\me\app.log or \\wsl$\Ubuntu\...), from the command line, Open file…, Open folder… and the recents.

  • Saving writes a temporary file next to the original and renames it over it. Where a share does not allow that, ted writes into the file directly instead.
  • Some shares, and WSL, do not report changes made by other programs. ted then checks the open file when its window gets the focus back.
  • Git may refuse a repository on a share or in WSL as unsafe (safe.directory); the Git panel shows git's own message.
  • A Linux path such as /home/me/app.log, typed in a WSL terminal for the Windows ted.exe, is not translated: use ted.exe "$(wslpath -w app.log)".

Log file

ted writes what it does to its log file: what was opened, how long it took, warnings and errors. It never writes the contents of your files or what you type. When the file reaches 5 MB it is renamed to ted.1.log, and at most ten files are kept. The log_level setting and the TED_LOG variable choose how much is written; see Command line.
