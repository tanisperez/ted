title: Troubleshooting description: What to do when ted does not start, a file does not open, or something looks wrong. ---

Troubleshooting

Most problems leave a trace in the log file. Run ted with more detail to see it:

```shell $ TED_LOG=debug ted ```

A file opens read only

Either it is not valid UTF-8, and ted shows it with replacement characters instead of changing its bytes on save, or it is a big file that is still loading: its first screen shows at once, and editing starts when the whole text is there. The status bar shows UTF-8 (read only) in the first case.

A file has no colors

Check the language at the right of the status bar. Plain text means ted does not know the file type; see Languages. A file bigger than 4 MB stays plain on purpose; see Big files.

A file or folder does not show in the explorer

It may be listed in a .gitignore, or match the Exclude setting.

ted does not start on Linux

ted needs a Wayland or X11 session and the system libraries its package lists as dependencies. Run it from a terminal to see the error.

Reporting a problem

Open an issue on GitHub with your system, the version (ted --version) and the end of the log file.
