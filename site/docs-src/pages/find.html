Find in file

Ctrl F opens the find bar across the top of the editor, with the selected text in it when the selection is on one line. A selection over several lines turns on Find in selection instead.

Using the find bar

  • Type, and ted selects the first match after the cursor. Every match on screen is tinted, and the scrollbar marks where the matches of the whole file are, the selected one in a stronger color.
  • Enter or F3 goes to the next match, Shift Enter or Shift F3 to the previous one, wrapping around the end of the file. The arrows of the bar do the same.
  • The counter shows which match is selected, 3 of 120, or No results.
  • Esc or the cross closes the bar and puts the cursor back in the text, the match still selected.

Options

Three buttons inside the field change how the text matches. Each one has a key while the bar has the focus:

  • Match case (Alt C) makes the search case sensitive. Without it, the search ignores case in every language.
  • Whole words (Alt W) only finds the text when it is not part of a longer word: find does not match inside finder.
  • Regular expression (Alt X) reads the text as a pattern, in the syntax of Rust's regex crate: \d+, ^fn, (\w+)=(\w+). ^ and $ are the start and the end of a line. A pattern with an error shows Invalid pattern in the counter. Without it, the text is matched literally: a . or a * means itself.

Find in selection, the button after the arrows, limits the search to the text selected when it is turned on. Press it again to search the whole file.

Replace

Ctrl R or Ctrl H (Cmd R or Cmd Option F on macOS), or the arrow at the left of the bar, shows a second field for the replacement.

  • Replace, or Enter in the replacement field, replaces the selected match and selects the next one. When the selection is not a match, it selects the next match first.
  • Replace all replaces every match of the file (or of the selection, with Find in selection) at once, searched in the background, as one step that Ctrl Z undoes.
  • With Regular expression on, $1, $2 and ${name} in the replacement put the groups of the match: (\w+)=(\w+) replaced with $2=$1 turns a=b into b=a. $$ is a $.
  • Preserve case, the AB button of the replacement field, keeps the case of each match: replacing find with search turns Find into Search and FIND into SEARCH.
  • A read only file cannot be replaced in.

Big files

ted counts the matches in the background, a few megabytes at a time, so the window never waits; a 100 MB log is counted in about 30 ms. While it counts, the counter ends in …. When a file has more than 100,000 matches, next and previous still work, and the counter shows the total.
