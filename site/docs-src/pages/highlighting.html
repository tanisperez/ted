title: Syntax highlighting description: The languages ted highlights, how it detects them, and how it handles logs and big files. ---

Syntax highlighting

ted colors code with tree-sitter, in the background, and keeps the colors in step as you type. Logs get a highlighter of their own, fast at any size.

Languages

The language comes from the file name and its extension, and shows at the right of the status bar. A file whose name says nothing, such as a script without an extension, takes its language from its first line when it is a shebang (#!/bin/sh, #!/usr/bin/env python3).

Python.py, .pyw, .pyi, and a python shebang
Log.log

Anything else is Plain text. In Markdown, headings, lists, quotes and code blocks are colored; inline code and emphasis are not yet.

Logs

In a .log file, the date and time at the start of each line and the level word (ERROR, WARN, INFO, DEBUG, TRACE, and FATAL, ERR, WARNING) are colored. Only the lines on screen are looked at, so a log of any size scrolls as fast with colors as without.

Big files

A file bigger than 4 MB is not parsed and stays plain, so a huge generated JSON never costs a long parse or the memory of its tree. The limit is the highlight_max_size_mb key of settings.toml. Logs are highlighted at any size.
