title: Installation description: How to install ted on Windows, macOS and Linux, put it on the PATH, and build it from source. ---

Installation

Every release on GitHub has packages for Windows x86_64, macOS on Apple silicon and Linux x86_64. The download page links to them.

Windows

Run ted-X.Y.Z-windows-x86_64-setup.exe. It installs ted for your user only, under %LOCALAPPDATA%\Programs\ted, and needs no administrator rights. The installer offers three options:

  • Add ted to the PATH, checked: run ted file.txt or ted . from any new terminal. Uninstalling removes it again.
  • Add "Open with ted" to the Explorer menu, checked: on every file, on folders and on the background of an open folder.
  • Create a desktop shortcut, unchecked.

ted also shows in the Open with list of the usual text files (.txt, .md, .log, .json and others) without becoming their default app. To use ted without installing anything, unzip ted-X.Y.Z-windows-x86_64-portable.zip and run ted.exe.

macOS

Open ted-X.Y.Z-macos-arm64.dmg and drag ted to Applications. ted then shows in Finder's Open With menu of text files and folders. A Mac app cannot put itself on the PATH; to run ted from a terminal, link it once:

```shell $ sudo ln -sf /Applications/ted.app/Contents/MacOS/ted /usr/local/bin/ted ```

Linux

The packages install ted in /usr/bin, with its desktop entry and icons, so ted shows in your applications menu and in the Open With menu of text files and folders.

```shell # Debian and Ubuntu $ sudo apt install ./ted_X.Y.Z_amd64.deb # Fedora and openSUSE $ sudo dnf install ./ted-X.Y.Z-1.x86_64.rpm # Arch Linux $ sudo pacman -U ./ted-X.Y.Z-1-x86_64.pkg.tar.zst ```

The AppImage, ted-X.Y.Z-x86_64.AppImage, runs on any distribution once it is executable (chmod +x), and installs nothing. The tarball, ted-X.Y.Z-linux-x86_64.tar.gz, holds bin/ted and the desktop files in a /usr layout, to copy wherever you like.

First launch

ted is not code signed yet. On macOS, if the system says it cannot verify the developer, choose Open Anyway in System Settings, Privacy and Security. On Windows, if SmartScreen shows Windows protected your PC, choose More info and then Run anyway.

Every release lists the SHA-256 checksum of each package in SHA256SUMS.

Building from source

ted builds with the stable Rust toolchain. On Linux it needs the development packages of Wayland, X11, xkbcommon, fontconfig and Vulkan; the README lists them.

```shell $ git clone https://github.com/tanisperez/ted $ cd ted $ make release $ ./target/release/ted ```
