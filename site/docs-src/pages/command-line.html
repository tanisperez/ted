title: Command line description: Running ted from a terminal: opening files and folders, options and environment variables. ---

Command line

The installers put ted on your PATH (on macOS, see Installation). From a terminal it opens what you name, and returns at once.

```shell $ ted notes.md # a file on its own $ ted . # the current folder, with the explorer $ ted a.txt b.txt # several files, each in its tab $ ted . README.md # a folder, with a file open in a tab $ ted # the recent files and folders ```

Arguments

  • Files open each in its own tab, in order. With a folder among them, the folder opens with the explorer and the files in its tabs; only the first folder given is opened.
  • A path that does not exist shows an error in the window.
  • After --, every argument is a path, even one that starts with a dash: ted -- -notes.txt.

Options

OptionWhat it does
-h, --helpPrints the usage and exits.
-V, --versionPrints the version and exits.

Any other option is an error: ted prints error: unknown option and exits with code 2.

Environment variables

VariableWhat it does
TED_LOGThe log level of this run: off, error, warn, info, debug or trace. Overrides the log_level setting.
