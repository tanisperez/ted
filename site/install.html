Download ted

Free and open source. Pick your system below. Every package is on the latest GitHub release, with its SHA-256 checksum in SHA256SUMS.

  • Windows

    Windows 10 and 11, 64 bit. The installer is for your user only and needs no administrator rights. It adds ted to the Start menu, puts ted on your PATH and adds Open with ted to the Explorer menu of files and folders. The portable zip needs no installer at all.

    Download the installer File ted-…-windows-x86_64-setup.exe Download the portable zip File ted-…-windows-x86_64-portable.zip

  • macOS

    Apple silicon (M1 and later). Open the disk image and drag ted to Applications. ted then shows in the Open With menu of text files and folders.

    Download the disk image File ted-…-macos-arm64.dmg

  • Linux

    x86_64. A .deb, an .rpm, an Arch package, an AppImage and a tarball. The packages install ted in /usr/bin with its desktop entry and icons.

    Download a package Files .deb, .rpm, .pkg.tar.zst, .AppImage, .tar.gz
Install

From the command line

Download the package of the latest release, then install it with your package manager.

Debian and Ubuntu apt

$ sudo apt install ./ted_*_amd64.deb

Fedora and openSUSE dnf, zypper

$ sudo dnf install ./ted-*.x86_64.rpm

Arch Linux pacman

$ sudo pacman -U ./ted-*-x86_64.pkg.tar.zst

macOS terminal

A Mac app cannot put itself on the PATH. To run ted from a terminal, link it once:

$ sudo ln -sf /Applications/ted.app/Contents/MacOS/ted /usr/local/bin/ted
First launch

A note on unsigned builds

ted is not code signed yet, so your system asks once before opening it.

macOS

If macOS says it cannot verify the developer, open System Settings, Privacy and Security, and choose Open Anyway. Or run this once:

$ xattr -dr com.apple.quarantine /Applications/ted.app

Windows

If SmartScreen shows Windows protected your PC, choose More info and then Run anyway.

Build from source

ted builds with the stable Rust toolchain. Clone the repository and run make release. The README lists the system libraries Linux needs.
