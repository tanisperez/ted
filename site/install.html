Download ted

Free and open source. Pick your system below, or install it with your package manager to get updates with the rest of your software.

  • Windows

    Windows 10 and 11, 64 bit. The installer is for your user only and needs no administrator rights. It adds ted to the Start menu, puts ted on your PATH and adds Open with ted to the Explorer menu of files and folders. It updates itself. The portable zip needs no installer at all.

    Download the installer File ted-…-windows-x86_64-setup.exe Download the portable zip File ted-…-windows-x86_64-portable.zip

  • macOS

    Apple silicon (M1 and later). Open the disk image and drag ted to Applications. ted then shows in the Open With menu of text files and folders. Updates itself.

    Download the disk image File ted-…-macos-arm64.dmg

  • Linux

    x86_64. A .deb, an .rpm, an Arch package, an AppImage and a tarball. Use a repository below to get updates, or the install script on any distribution.

    Download File ted-…-x86_64.AppImage

Package managers

Install from the command line

Each channel is updated with every release, so your usual upgrade command keeps ted up to date.

Any Linux distribution install script

Installs ted for your user under ~/.local, no sudo. ted then updates itself, or run the script again. Options and uninstall.

$ curl -fsSL https://ted.tanis.codes/install.sh | bash

Debian and Ubuntu apt

Add the signing key and the repository once, then install.

$ sudo curl -fsSLo /etc/apt/keyrings/ted.asc https://ted.tanis.codes/ted.asc
$ echo "deb [signed-by=/etc/apt/keyrings/ted.asc] https://ted.tanis.codes/apt stable main" \
    | sudo tee /etc/apt/sources.list.d/ted.list
$ sudo apt update && sudo apt install ted-editor

Fedora and openSUSE dnf, zypper

Add the repository once, then install. The key is imported on the first install.

# Fedora
$ sudo curl -fsSLo /etc/yum.repos.d/ted.repo https://ted.tanis.codes/rpm/ted.repo
$ sudo dnf install ted-editor

# openSUSE
$ sudo zypper addrepo https://ted.tanis.codes/rpm/ted.repo
$ sudo zypper install ted-editor

Arch Linux pacman

Download the Arch package of the latest release, then install it. It is not in the AUR yet.

$ sudo pacman -U ./ted-editor-*-x86_64.pkg.tar.zst

macOS terminal

A Mac app cannot put itself on the PATH. To run ted from a terminal, link it once:

$ sudo ln -sf /Applications/ted.app/Contents/MacOS/ted /usr/local/bin/ted
First launch

A note on unsigned builds

ted is not code signed yet, so your system asks once before opening it.

macOS

If macOS says it cannot verify the developer, open System Settings, Privacy and Security, and choose Open Anyway. Or run this once:

$ xattr -dr com.apple.quarantine /Applications/ted.app

Windows

If SmartScreen shows Windows protected your PC, choose More info and then Run anyway.

Build from source

ted builds with the stable Rust toolchain. Clone the repository and run make release. The README lists the system libraries Linux needs.
